# Security

If you find a security problem in Karaoke Night, please **do not post it in a public issue**.

Report it privately instead: open the **Security** tab of this repository, choose **Report a vulnerability**, and describe what you found
and how to reproduce it. You will get an answer as soon as possible. Please give me reasonable time to fix it before sharing details publicly.

Only the **latest release** is supported with fixes; the app updates itself on Windows, and on Android you install the newest `.apk`.
